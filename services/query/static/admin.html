Users

The same operations as ragctl user, for members. Admin accounts -- making, demoting, editing, disabling or deleting one -- are only managed at the terminal, with ragctl user. is_admin is the only role: an admin can do anything to any library, everyone else only chats and works within the libraries they own or were given access to.

Libraries

A library is a named set of documents with an owner. The owner (or an admin) has full control; everyone else needs a read or write row in its access list to search or cite it -- a user with no access is never told it exists.

Documents

Every indexed document, and which libraries it belongs to. A document in no library is reachable only by an admin.

Configuration

The repository's .env, as text. It is checked against the real config loaders before it is written, and the previous version is kept in data/env-backups/. Values are shown unmasked — secrets included — because masking could not be saved back.

Applying changes

A saved file changes nothing until it is applied. Most settings are picked up by a live reload; a few can only be reached by restarting the service or the whole stack, and the buttons say which.
