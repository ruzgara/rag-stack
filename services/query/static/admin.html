Libraries

A library is a named set of documents. library.read on one lets a user search and cite it; a user who can't read a library is never told it exists.

Configuration

The repository's .env, as text. It is checked against the real config loaders before it is written, and the previous version is kept in data/env-backups/. Values are shown unmasked — secrets included — because masking could not be saved back.

Applying changes

A saved file changes nothing until it is applied. Most settings are picked up by a live reload; a few can only be reached by restarting the service or the whole stack, and the buttons say which.
